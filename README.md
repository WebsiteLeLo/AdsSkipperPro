# Ads Skipper Pro

Ads Skipper Pro is an advanced, fully modular browser extension designed to bypass link shorteners, ad-walls, and countdown timers safely and automatically.

## Features
- **Smart Shortener Detection:** Automatically detects when you are on a supported link shortener and activates. Remains 100% inactive on normal websites to prevent accidental clicks.
- **Server Timer Sync:** Intelligently handles server-side timers (e.g. Arolinks, TipsGuru) by showing a sleek full-screen timer and proceeding only when the native token is ready.
- **Aggressive Ad Blocking:** Freezes background popups and removes fake "Click on ad" overlays.
- **Safe Clicker:** Bypasses disabled buttons and hidden links without breaking the site's anti-bot verification.
- **Premium UI:** Features a sleek, modern popup interface and full-screen loading indicators.

## Installation on PC (Chrome, Edge, Brave, Opera)
1. Download the latest `AdsSkipperPro.zip` file from the releases.
2. Extract the ZIP file to a folder on your computer.
3. Open your browser and go to the Extensions page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
4. Turn on **Developer mode** (usually a toggle in the top right corner).
5. Click on the **Load unpacked** button.
6. Select the folder where you extracted the ZIP file.
7. The extension is now installed! You can pin it to your toolbar for easy access.

## Installation on Mobile (Android via Kiwi Browser)
Kiwi Browser is a Chromium-based browser for Android that supports desktop extensions.
1. Download and install **Kiwi Browser** from the Google Play Store.
2. Download the `AdsSkipperPro.zip` file directly to your phone.
3. Open Kiwi Browser and tap the three dots (`⋮`) in the top right corner.
4. Select **Extensions** from the menu.
5. Turn on **Developer mode**.
6. Tap on **+(from .zip/.crx/.user.js)**.
7. Select the `AdsSkipperPro.zip` file you downloaded.
8. The extension will be installed and activated automatically.

## How It Works
Once installed, the extension works entirely in the background. When you visit a supported link shortener (like Arolinks, TipsGuru, etc.):
- It will automatically detect the hidden destination URL or bypass the timer.
- If a site requires a mandatory server-side wait, you will see a full-screen **"Bypassing..."** timer. Do not close the tab; it will automatically redirect you once the wait is over.
